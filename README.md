This is my code sample for Predoctoral Research positions. It is a copy of the code I used to clean and analyze data, perform robustness checks, and generate figures for my research on Vermont Act 76. 
Essential for this project is having the data. 
A link to a .gz file with the raw data and a .md file listing all components of the extract can be found in this Google Drive link:
https://drive.google.com/drive/folders/1xpqvrsA05jlBcjkyc9vS3_YpVeboz40Q?usp=sharing
You MUST download the data into the project folder before running the code.
All code was authored by Ethan M. Lapin and is designed to run in Stata Version 19. File 00_master.do contains code to install all necessary packages.
